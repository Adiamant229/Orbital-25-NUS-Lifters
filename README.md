## 🧪 Local Development Setup

### 1. ⚙️ Prerequisites
Make sure you have the following installed:

- 🟢 Node.js (preferably the latest LTS version)
- 🚀 Expo CLI:

```bash
npm install -g expo-cli
```
- 📝 A code editor like VS Code
- 📱 A mobile device with the Expo Go app installed (available on iOS App Store and Google Play Store)
- 🖥️ Or an emulator/simulator set up on your computer

### 2. 📂 Clone the Project Repository
Clone the project to your local machine:

```bash
git clone https://github.com/Sengernest/Orbital-25-NUS-Lifters.git
cd Orbital-25-NUS-Lifters
```

### 3. 📦 Install Project Dependencies
Inside the project directory, run:

```bash
npm install
```

### 4. ▶️ Start the Expo Development Server
Run the development server:

```bash
npx expo start
```

### 5. 📲 Run Your App

On a physical device:
Download and open the Expo Go app on your phone and scan the QR code displayed in the Expo Dev Tools or terminal.

On an Android emulator:
Make sure you have Android Studio and an emulator set up. Press a in the terminal or click “Run on Android device/emulator” in Expo Dev Tools.

On an iOS simulator:
Make sure you have Xcode installed. Press i in the terminal or click “Run on iOS simulator” in Expo Dev Tools.
